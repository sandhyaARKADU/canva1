# Plan: Professional Selection Border, Floating Toolbar, and Three-Dot Action Menu

## Audit Summary

### Existing Architecture
- **Canvas library**: Fabric.js v5.3.0
- **Selection styling**: Purple border (#8b5cf6), white circle corners (10px), borderScaleFactor 2 — set globally on `fabric.Object.prototype` in `CanvasWorkspace.tsx:35-42`
- **Selection flow**: Canvas events → `setSelectedObject()` in Zustand store → all UI components subscribe
- **Floating toolbar** (`ElementToolbar.tsx`): Fixed at top-center of canvas area, NOT positioned near the selected element. No overflow/three-dot menu.
- **ContextMenu** (`ContextMenu.tsx`): Right-click menu works, has Copy/Paste/Layer/Flip/Rotate/Group — but NO alignment submenu
- **PropertiesPanel**: Has full controls including AlignmentTools, but behind a tab
- **SmartResize**: Resizes canvas directly, bypasses store's `canvasWidth/canvasHeight`
- **loadProject**: Does NOT update `canvasWidth/canvasHeight` in store after loading

### Root Causes
1. **Toolbar is fixed-positioned** — Editor.tsx wraps it in `absolute top-3 left-1/2 -translate-x-1/2`
2. **No three-dot overflow menu** exists anywhere in the editor
3. **Alignment is only in PropertiesPanel** — not in floating toolbar or context menu
4. **Store dimensions are stale** after loadProject and SmartResize

### Step 2: Rewrite ElementToolbar — Floating Position + Three-Dot Menu

**File: `frontend/src/components/editor/ElementToolbar.tsx`** — Full rewrite

**Key changes:**
- Render via `createPortal(document.body)` to avoid `overflow-hidden` clipping
- Compute position from `selectedObject.getBoundingRect(true, true)` + canvas viewport transform
- Listen to `after:render`, `object:modified`, `selection:created/updated` to reposition
- Add `MoreVertical` (three-dot) button at the end
- Add dropdown menu with Layer, Align, Lock, Group, Duplicate, Delete actions
- Add alignment submenu with 7 alignment options using existing `alignObjectToPage()`

**Position calculation:**
```typescript
const updatePosition = () => {
  if (!canvas || !selectedObject) return;
  const zoom = canvas.getZoom();
  const vpt = canvas.viewportTransform || [1, 0, 0, 1, 0, 0];
  const bounds = selectedObject.getBoundingRect(true, true);
  const canvasEl = canvas.getElement();
  const canvasRect = canvasEl.getBoundingClientRect();

  // Object top-center in screen coordinates
  const centerX = canvasRect.left + (bounds.left + bounds.width / 2) * zoom + vpt[4];
  const topY = canvasRect.top + bounds.top * zoom + vpt[5];

  const toolbarWidth = 480;
  const gap = 8;

  let left = centerX - toolbarWidth / 2;
  let top = topY - 44 - gap; // 44px toolbar height + gap

  // If above canvas, place below
  if (top < canvasRect.top) {
    top = canvasRect.top + (bounds.top + bounds.height) * zoom + vpt[5] + gap;
  }

  // Clamp horizontally
  left = Math.max(canvasRect.left + 4, Math.min(left, canvasRect.right - toolbarWidth - 4));

  setToolbarPos({ left, top });
};
```

**Three-dot menu items:**
```
Layer
├── Bring to Front        canvas.bringToFront(obj)
├── Bring Forward         canvas.bringForward(obj)
├── Send Backward         canvas.sendBackwards(obj)
└── Send to Back          canvas.sendToBack(obj)
─────────────────────────
Align to Page        → [submenu]
  ├── Align Left          alignObjectToPage(canvas, obj, 'left')
  ├── Align Center (H)    alignObjectToPage(canvas, obj, 'center-horizontal')
  ├── Align Right         alignObjectToPage(canvas, obj, 'right')
  ├── Align Top           alignObjectToPage(canvas, obj, 'top')
  ├── Align Center (V)    alignObjectToPage(canvas, obj, 'center-vertical')
  ├── Align Bottom        alignObjectToPage(canvas, obj, 'bottom')
  └── Align Center        alignObjectToPage(canvas, obj, 'center')
─────────────────────────
Lock / Unlock
Hide / Show
─────────────────────────
Group                 (disabled if not multi-select)
Ungroup               (disabled if not group)
─────────────────────────
Duplicate
Delete (red)
```

**Edge cases handled:**
- **Text editing mode**: Hide toolbar when `canvas.getActiveObject().isEditing` (listen to `text:editing:entered/exited`)
- **Multi-selection**: Position above bounding rect of entire selection; enable Group, disable Ungroup
- **Locked objects**: Show toolbar with lock icon highlighted; all controls still work (lock/unlock is a toggle)
- **Off-screen objects**: Clamp toolbar to stay within viewport

## Verification

1. **Selection outline**: Click any element → purple outline appears with circle resize handles and rotation control
2. **Floating toolbar position**: Toolbar appears above the selected element, repositions on move/drag/zoom
3. **Three-dot menu**: Click `⋮` → dropdown appears with Layer, Align (submenu), Lock, Hide, Group, Duplicate, Delete
4. **Alignment submenu**: Hover "Align to Page" → 7 alignment options expand to the right; clicking aligns the element to the page
5. **Context menu alignment**: Right-click → "Align to Page" submenu appears with same 7 options
6. **Store dimensions**: After resize via SmartResize, `canvasWidth`/`canvasHeight` in store match actual canvas dimensions
7. **Project reload**: Load a project → canvas dimensions correct, store dimensions match
8. **Undo/redo**: All toolbar actions, context menu actions, and alignment actions are recorded in history
9. **Multi-select**: Select multiple elements → toolbar positions above combined bounding rect; Group enabled, Ungroup disabled
10. **Text editing**: Double-click text → toolbar hides; click outside → toolbar reappears

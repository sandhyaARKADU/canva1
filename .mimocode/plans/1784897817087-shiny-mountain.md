### Root Cause: What's Actually Incomplete

1. **Sidebar templates tab has NO ratio filtering** — loads all 48 templates regardless of current canvas dimensions
2. **Template card aspect ratio is hardcoded to 4/5** — doesn't reflect actual template dimensions
3. **No "Apply to Current Canvas" flow** — "Use Template" always creates a NEW project, never applies to the existing open canvas
4. **Sidebar templates tab is bare-bones** — no search, no categories, no type filtering, no favourite toggle, no preview modal
5. **No design-ratio compatibility matching** — templates aren't filtered by whether they match the current project type
6. **Backend has no ratio-based filtering** — no `width`/`height` or `aspect_ratio` query params

## Implementation Plan

### Step 1: Add Ratio-Based Template Filtering to Backend

**File**: `backend/routes/templates.py`

Add optional `min_width`, `max_width`, `min_height`, `max_height`, `orientation` query params to `GET /api/templates`. This allows the frontend to request templates matching the current canvas dimensions.

```python
# In list_templates endpoint, add:
min_width: Optional[int] = None,
max_width: Optional[int] = None,
min_height: Optional[int] = None,
max_height: Optional[int] = None,
orientation: Optional[str] = None,  # "portrait", "landscape", "square"
```

Add filtering logic:
```python
if min_width: query = query.filter(Template.width >= min_width)
if max_width: query = query.filter(Template.width <= max_width)
if min_height: query = query.filter(Template.height >= min_height)
if max_height: query = query.filter(Template.height <= max_height)
if orientation == "portrait": query = query.filter(Template.width < Template.height)
elif orientation == "landscape": query = query.filter(Template.width > Template.height)
elif orientation == "square": query = query.filter(Template.width == Template.height)
```

### Step 2: Add "Apply to Current Canvas" Backend Endpoint

**File**: `backend/routes/templates.py`

Add `POST /api/templates/:id/apply` endpoint that applies template data to an EXISTING project (instead of creating a new one). This is the key missing piece.

```python
@router.post("/{template_id}/apply")
def apply_template_to_project(
    template_id: str,
    project_id: str,  # passed as query param or body
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    template = get_template_or_404(template_id, db)
    project = db.query(Project).filter(
        Project.id == project_id,
        Project.user_id == current_user.id,
    ).first()
    if not project:
        raise HTTPException(status_code=404, detail="Project not found")

    canvas, canvas_width, canvas_height = _load_template_canvas(template)
    project.data = _compact_json(canvas)
    project.width = canvas_width
    project.height = canvas_height
    # Save design version
    db.add(DesignVersion(...))
    template.use_count = (template.use_count or 0) + 1
    db.commit()
    return {"success": True, "project": project_to_response(project)}
```

### Step 5: Add Ratio Compatibility Matching Utility

**File**: `frontend/src/utils/templateCompatibility.ts` (new file)

Create utility to check if a template is compatible with current canvas dimensions:

```typescript
interface TemplateCompatibility {
  presetIds: string[];
  aspectRatio: number;
  orientation: 'portrait' | 'landscape' | 'square';
  allowSmartResize: boolean;
}

export function isTemplateCompatible(
  templateWidth: number,
  templateHeight: number,
  canvasWidth: number,
  canvasHeight: number,
  tolerance = 0.15
): boolean {
  const templateRatio = templateWidth / templateHeight;
  const canvasRatio = canvasWidth / canvasHeight;
  return Math.abs(templateRatio - canvasRatio) / canvasRatio <= tolerance;
}

export function getTemplateOrientation(width: number, height: number): string {
  if (width === height) return 'square';
  return width > height ? 'landscape' : 'portrait';
}
```
